欢迎来到我的个人主页！
这是一个模拟 Linux 终端的网页，可以用一些简单的 Linux 命令。
这里藏着一些我的信息，也有一些有趣的小彩蛋。
用命令探索这个网站，看看你能发现什么吧！

如果你不会用命令，没关系，我简单介绍一下：
- `cd`     进入一个目录，如 `cd projects`，返回上一级用 `cd ..`
- `ls`     显示当前目录下的文件和文件夹，蓝色的是文件夹
- `pwd`    显示当前所在的目录
- `cat`    显示一个文件的内容，如 `cat contact.md`
- `clear`  清空屏幕，也可以按 Ctrl+L
- `blog`   跳转到我的博客
- `comment` 打开留言板，给我留句话吧

还有一些好用的快捷键：
- Tab      接受灰色提示，或者补全命令和文件名
- Ctrl+C   放弃当前输入
- Ctrl+L   清空屏幕
- ↑        上一条输入过的命令
- ↓        下一条输入过的命令
